Append one entry to `docs/log.md`.

- Read the last entry and run `git status --short` first, so the entry covers only the work since then.
- A short title, then `Decided`, `Done`, `Verified`, `Open`, `Next`. Omit empty headings. No dates in the title or the body.
- Decisions carry the reason. Files created or changed go under Done. Verification goes under Verified with the exact commands and their result.
- Twelve lines is the target. No transcript, no code blocks, no restating the conversation.
- Append only. Never edit or reorder older entries.

The file is gitignored. Write it anyway.
